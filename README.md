# OwRandomizer

守望先锋自定义房间 5v5 / 6v6 随机分队。React + Vite + Tailwind + shadcn/ui。

线上：https://xbx0721.github.io/OwRandomizer/

```bash
npm install
npm run dev
npm run build
```

设置记在本机。开局后链接可分享，复制结果可直接发群。

推到 `main` 后，GitHub Actions 会发布 GitHub Pages。第一次需要在仓库 Settings → Pages → Source 选 GitHub Actions。
